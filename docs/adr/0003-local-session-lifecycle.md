# 本站会话独立于 Keycloak SSO 生命周期

本站继续使用 Cookie 会话，移除原有延长至 30 天的“记住我”，默认闲置超时为 30 分钟并允许配置。登录持久性由 Keycloak SSO 管理；用户主动再次登录时可以利用 SSO 建立新的本站会话。

退出操作仅作废本站会话，不结束 Keycloak SSO，以免影响其他共享统一认证的应用。本次不实现 Keycloak 禁用用户或外部退出后的即时本站会话撤销，已建立的本站会话可能保持有效；闲置会话在超时后失效，持续活跃的会话则需退出或由服务器作废后才失效。

以上决定已由用户确认。这种独立生命周期避免了每个业务请求依赖 Keycloak 可用性，但不提供跨应用实时退出或实时账户禁用。
