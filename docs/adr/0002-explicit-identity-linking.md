# 显式关联统一身份与本站用户

OIDC 接入保留已有本站用户 ID，以及依赖这些 ID 的部门和项目关联；旧账户通过显式绑定关联 Keycloak 身份，不凭同名用户名或邮箱自动合并。自动合并虽然更便捷，但用户名或邮箱相同不足以证明访问者拥有旧账户，错误关联可能授予既有业务权限。

身份关联使用 OIDC 的 issuer 与 subject 标识。维护者使用一次性管理命令提供经过确认的本站用户 ID 与统一身份对照表；新部署通过配置指定首个管理员的统一身份。以上方式已由用户确认，不依赖环境中是否已有真实用户数据。

现有 `user_cloaks` 中的值由开发数据初始化器随机生成，缺少 issuer 和身份唯一性约束，不能当成已经验证的统一身份绑定。
